# Mingle

让 AstrBot 像群友一样参与聊天：平时旁听，合适时接话，也能跟上聊天中的补充和纠正。

## 有什么亮点？

- **不用每次 @**：结合人设和聊天上下文，判断是否值得接话；被 @ 或私聊时直接进入回复流程。
- **等你说完再接话**：短时间内的多条消息合并处理，明显没说完的内容会先等待。
- **回复期间也能听见新消息**：普通补充排队处理；重要纠正、改口或停止请求，可触发重跑或停止。
- **保留熟悉的人设和能力**：沿用 AstrBot 配置的对话模型、人设及已启用工具。接话判断也可单独选择模型、调整提示词。
- **按需翻聊天记录、看图片**：模型可以查询更早的聊天、重新查看缓存图片。图片发送前压缩，GIF 取首帧；历史图片下一轮移出上下文，避免不断堆积。
- **附带常用工具**：查询会话时区的日期和时间、计算算术表达式、掷骰子或抽签。额外工具箱支持独立开关与一键全关。

## 开始使用

需要 **AstrBot 4.29.3 或更新版本**：

1. 安装插件，并在 AstrBot 中配置好对话模型。
2. 由 AstrBot 管理员在目标群发送 `/mingle group on` 开启该群。
3. 正常聊天即可。私聊默认接管，可在插件配置中关闭。

管理员可发送 `/mingle` 查询命令帮助。

## 配置调整

**Mingle 配置**

在管理面板的「插件」中，进入 Mingle 插件配置页面即可配置。Mingle 设计为即开即用插件，默认配置即可使用，也可根据需求进行调整。

**AstrBot 配置**

Mingle 的某些功能依赖 Astrbot 的框架实现，但某些功能与 Astrbot 相冲突，为了正常使用，请按下文方式调整。

在管理面板的「配置文件」中，然后检查以下项目：

- **配置文件 → AI → 启用 AI**：开启（Mingle 依赖 Astrbot 框架提供的智能体）。
- **配置文件 → 平台与消息 → 基本 → 隔离对话**：关闭（Mingle 设计为群成员共享上下文）。
- **配置文件 → 扩展功能 → 群聊上下文感知 → 群聊消息记录注入上下文**：关闭（Mingle 将自行记录并提供群聊上下文，不使用 Astrbot 框架逻辑）。
- **配置文件 → 扩展功能 → 群聊上下文感知 → 主动回复**：关闭（Mingle 将自行判断接话时机，不使用 Astrbot 框架逻辑）。
- **人格设定 → 对应人格 → 配置工具**：确保 Mingle 工具均启用（Mingle 依赖这些工具实现其功能）。
